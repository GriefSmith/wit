# Hide UI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A Hide UI checkbox in the gear menu clears the app chrome and eases the current writing column into the center without changing its measure.

**Architecture:** `readStoredHideUi` is a pure localStorage reader. App owns the boolean, writes `wit-hide-ui`, and sets `data-hide-ui="on"` on `<html>`. The gear menu renders the checkbox. CSS collapses the header and the sidebar slot over 240ms; the column is already centered, so it glides. The rail fades in place and keeps its width, so a closed sidebar does not slide the column. The gear is portaled to `document.body` while the mode is on so the collapsed header cannot clip it, and it is placed on the header's right corner.

**Tech Stack:** React 19, TypeScript, existing CSS. Node's built-in test runner (`node --experimental-strip-types --test`). No component test runner.

**Spec:** `docs/superpowers/specs/2026-11-14-hide-ui-design.md`

## Global Constraints

- The gear row label is `Hide UI`. It is the last row, under Background. The control is a checkbox. The row uses the same grid as the other gear rows.
- Storage key is `wit-hide-ui`. `"1"` means on. `"0"`, a missing key, and any other string mean off.
- While on, `<html>` carries `data-hide-ui="on"`. While off, that attribute is absent.
- The saved sidebar open flag (`wit-sidebar-open`) and the saved sidebar width (`wit-sidebar-width`) are not changed by the toggle.
- Hidden, non-interactive, and out of the tab order: header title, `.wit-page-search`, save cluster, duplicate-id notice, mounted sidebar and its resize handle, sidebar rail (show-pages button and collapsed pin control), `.wit-main-route-context`.
- The search shortcut does not open search while Hide UI is on.
- An open pin preview closes when Hide UI turns on.
- The gear stays, fixed to the viewport, in the corner it occupies in the header. Its menu still opens and closes, including to turn Hide UI off. Clicking outside still closes it. While the menu is open, the previous-page button stays hidden.
- Previous moves down to sit under the gear. Next stays at the bottom-right.
- Typing, block handles, the chapter opener menu, and the stale-markdown notice stay.
- The column keeps its resolved measure (`narrow` 58ch, `book` 66ch, `wide` 78ch, or uncapped). Do not edit those max-width rules.
- Sidebar slot and header height ease together for 240ms with `ease`. A sidebar that was open stays mounted; its used width animates to zero with overflow clipped, then back to the stored pixel width. A sidebar that was closed is not mounted and does not animate sideways.
- `prefers-reduced-motion: reduce` applies the same end state with no duration.
- Do not run `git commit` or `git push`. The commit blocks are for the human.

## File structure

- `frontend/src/lib/witAppearance.ts` — `HIDE_UI_STORAGE_KEY` and `readStoredHideUi`. No React.
- `frontend/test/hideUi.test.ts` — Node tests for that reader.
- `frontend/src/App.tsx` — boolean state, `<html>` attribute, storage write, pin-preview close, sidebar used width, inert chrome.
- `frontend/src/components/WitSettingsMenu.tsx` — checkbox row, and a body portal that parks the gear while the mode is on.
- `frontend/src/components/PageSearch.tsx` — ignore the shortcut and close the result list while the mode is on.
- `frontend/src/index.css` — collapse, fade, gear placement, previous-page offset, reduced motion. No measure changes.

```ts
import { readStoredHideUi } from '../src/lib/witAppearance.ts'

function installStorage(entries: [string, string][]) {
  const store = new Map(entries)
  globalThis.window = {
    localStorage: {
      getItem(key: string) {
        return store.has(key) ? store.get(key)! : null
      },
    },
  } as Window & typeof globalThis
}

test('readStoredHideUi is on only for the stored value 1', () => {
  const previous = globalThis.window
  try {
    installStorage([])
    assert.equal(readStoredHideUi(), false)
    installStorage([['wit-hide-ui', '0']])
    assert.equal(readStoredHideUi(), false)
    installStorage([['wit-hide-ui', 'true']])
    assert.equal(readStoredHideUi(), false)
    installStorage([['wit-hide-ui', '1']])
    assert.equal(readStoredHideUi(), true)
  } finally {
    if (previous === undefined) {
      delete (globalThis as { window?: unknown }).window
    } else {
      globalThis.window = previous
    }
  }
})

test('readStoredHideUi is off when window is missing', () => {
  const previous = globalThis.window
  try {
    delete (globalThis as { window?: unknown }).window
    assert.equal(readStoredHideUi(), false)
  } finally {
    if (previous !== undefined) {
      globalThis.window = previous
    }
  }
})
```

- [ ] **Step 3: Write the reader**

Append to `frontend/src/lib/witAppearance.ts`:

```ts
export const HIDE_UI_STORAGE_KEY = "wit-hide-ui";

/** `"1"` is on. Missing, `"0"`, and any other string are off. */
export function readStoredHideUi(): boolean {
  if (typeof window === "undefined") {
    return false;
  }
  return window.localStorage.getItem(HIDE_UI_STORAGE_KEY) === "1";
}
```

- [ ] **Step 2: Portal the gear and pin it to the header's corner**

In `frontend/src/components/WitSettingsMenu.tsx`, import `useLayoutEffect` from React and `createPortal` from `react-dom`.

Add this effect inside the component, next to the existing details effect:

```tsx
  useLayoutEffect(() => {
    if (!hideUi) {
      return;
    }
    const el = detailsRef.current;
    if (!el) {
      return;
    }
    const place = () => {
      const header = document.querySelector(".wit-app-header");
      if (!(header instanceof HTMLElement)) {
        return;
      }
      const rect = header.getBoundingClientRect();
      const pad =
        Number.parseFloat(getComputedStyle(header).paddingRight) || 0;
      el.style.top = "0.85rem";
      el.style.right = `${Math.max(0, window.innerWidth - rect.right + pad)}px`;

    place();

      window.removeEventListener("resize", place);
      el.style.top = "";
      el.style.right = "";
    };
  }, [hideUi]);
```
